# MeFlow

Broadcast rundown & production flow — Maqna Momento.

- **App:** https://maqnaverse.github.io/meflow/
- **Guest link:** `https://maqnaverse.github.io/meflow/?mode=guest&rd=<RUNDOWN_ID>`
- **Backend:** Google Apps Script + Google Sheets (MeFlow Database)

Halaman ini membungkus Web App Apps Script dalam iframe, simpan sesi login (iPhone/Safari),
pastikan skrin tak tidur semasa show, dan boleh di-*Install* sebagai app.

Untuk sambung: edit `index.html` → `EXEC_URL` = URL Web App (`https://script.google.com/macros/s/…/exec`).
